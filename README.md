# Craps Game 🎲

A simple Craps game built with Python.

## Rules
- Roll 7 or 11 on the first roll: **You win!**
- Roll 2, 3, or 12: **Casino wins!**
- Any other number becomes the goal.
- Roll the goal again to win, or roll 7 to lose.

## Technologies
- Python
- Random library
- Functions, conditions, loops, and lists

## How to Run

```bash
python3 main.py
```
